## 2025-06-07 - Parallelize Cloud Embedding Batching
**Learning:** Sequential calls to cloud embedding APIs for large batches present a significant performance bottleneck due to cumulative network latency. In `CloudEmbeddingBackend.embed_texts` in `src/wet_mcp/embedder.py`, text batches were being processed sequentially ($O(N)$ network roundtrips).
**Action:** Use `asyncio.gather` to dispatch embedding batches concurrently. This transforms the total latency from $O(N)$ to $O(\max(T_{batch}))$, significantly speeding up large batch processing without changing backend behavior. Ensure `MAX_BATCH_SIZE` is respected when constructing tasks for `gather`.
