## 2024-03-12 - Optimize String Splitting inside Crawler Discovery
**Learning:** Using `re.split` with multiple delimiters inside hot loops (like link discovery during crawling) can add up and create overhead because of regex evaluation. Replacing it with chained `str.replace` followed by a single `.split()` is significantly faster. Because the result is immediately cast to a `set()`, the extra empty strings generated by consecutive slashes (e.g., `//`) are safely collapsed, making the result functionally equivalent to the original regex split.
**Action:** Default to chaining `.replace()` over `re.split` when checking for multiple known single-character delimiters if performance is critical or happens inside a large iteration.
